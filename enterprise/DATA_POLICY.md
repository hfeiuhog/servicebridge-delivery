# 数据与发布边界

仅公开原创合成样本、预设参考标签及模型输出，不发布简历、真实联系方式、客户数据、运行数据库、生产日志或可用密钥。参考标签尚未独立人工复核。

DeepSeek 密钥通过环境或评测标准输入注入，仅存进程内。固定官方 API，不接受任意 base_url；key 不进入候选、Data、提示词或异常日志。能执行任意 Python 的平台管理员不在此隔离保证内。

原文先做有限联系方式清理，再发送模型。正则不是完整 DLP；真实数据需确认授权、供应商、保留和驻留规则。本次全部使用合成描述。

数据库保存当前清理后原文、候选、最终 Ticket、调用元数据和确认引用。事件记录版本、动作与摘要，不保留每轮完整原文和候选，不是完整历史重建或防篡改归档。保留期、加密、删除及备份由部署方案补齐。

生产审批私钥仅在外部审批侧，执行侧只持公钥。demo 临时生成私钥并模拟两个身份，不可当作生产职责隔离。
